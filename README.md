# my-skills — 수업 후 노션 정리 스킬 (`study-notes`)

AI 에이전트 3기 노드 06(MCP·스킬·하네스) 과제 제출물입니다.

## 왜 만들었나 (불편 → 해결)
- **불편**: 노드가 끝날 때마다 같은 부탁을 AI에게 반복했습니다. 노드 06 하루에만 "학습내용 정리", "의문 및 토론", "오늘의 회고"를 따로따로 시켰고, 그때마다 노션 템플릿 구조, 존댓말, "안 한 일은 한 일로 쓰지 말 것" 같은 조건을 처음부터 다시 설명해야 했습니다. 설명을 빼먹으면 결과 형식이 흔들렸습니다.
- **해결**: 위 조건을 `SKILL.md` 하나에 적어 두었습니다. 이제 "오늘 학습내용 정리해 줘" 한마디로 같은 구조와 말투가 나옵니다.

## 구성
```
.claude/skills/study-notes/SKILL.md
```
- `name`: study-notes
- `description`: 수업 후 노션 템플릿용 정리를 요청할 때 발동 (예: "학습내용 정리해 줘", "의문 토론 써", "회고 써")
- 본문: 요청 종류별(학습내용정리 / 의문 및 토론 / 회고) 작성 절차와 금지 사항

## 설치와 호출
1. 이 저장소의 `.claude/skills/study-notes/` 폴더를 적용할 프로젝트의 `.claude/skills/` 아래에 복사합니다(Claude Code 기준).
2. 도구를 재시작한 뒤 새 대화에서 호출합니다.
   - 예: `오늘 학습내용 정리해 줘` / `의문 및 토론 써 줘` / `오늘의 회고 써 줘`
